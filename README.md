# 景润跨境物流

跨境电商货运代理的运单查询原型。客户用运单号查看状态、预计到达时间和物流轨迹；内部人员在管理后台维护运单和物流节点。数据存在本机 SQLite，不需要单独安装数据库。

## 环境

- Node.js 22 或更高版本
- npm

## 启动

在项目目录执行：

```bash
npm install && npm start
```

浏览器打开 [http://localhost:43123](http://localhost:43123)。

第一次启动会自动创建 `data/jingrun.db`，并写入下面的示例运单。之后再启动会保留已修改的数据。若要恢复示例数据，先停掉服务，删除 `data/jingrun.db`，再执行 `npm start`。

## 页面

| 路径 | 谁在用 | 做什么 |
| --- | --- | --- |
| `/` | 客户 | 输入运单号查询，也可以点示例运单直接进入 |
| `/track/[运单号]` | 客户 | 查看当前状态、预计到达时间、货物摘要，以及按时间倒序的物流节点。每个节点有时间、地点和说明。查不到时显示未查询到运单 |
| `/admin` | 内部 | 运单列表。可按关键字和状态筛选，关键字匹配运单号、客户、货物、起运地、目的地 |
| `/admin/waybills/new` | 内部 | 新建运单：运单号、起运地、目的地、客户、货物、件数、重量、状态、预计到达、备注 |
| `/admin/waybills/[id]` | 内部 | 修改运单，添加、修改或删除物流节点。保存节点后，客户查询页的轨迹和当前状态会更新 |

管理后台没有登录。页面顶部有黄色提示：这是演示环境。地址是 [http://localhost:43123/admin](http://localhost:43123/admin)。

## 后台里改一票运单

1. 打开 [http://localhost:43123/admin](http://localhost:43123/admin)。
2. 点「新建运单」，填写运单号和必填项后创建。
3. 在同一页的「物流节点」里填写时间、地点、状态和说明，点「添加节点」。
4. 打开「客户查询页」，或回到首页用这个运单号查询。状态、预计到达时间和轨迹与后台一致。

列表里的「编辑」可以改已有运单。节点按时间最新的一条同步运单当前状态；也可以在运单资料里手动改状态，直到下一次保存节点。
